# Day 2 - Add trusted knowledge with Foundry IQ

From a general-purpose agent to a grounded healthcare assistant.

1. Inspect the supplied synthetic healthcare documents.
2. Configure a knowledge source and a Foundry IQ knowledge base (Azure AI Search backed).
3. Add a Medical Knowledge Agent and connect it to the knowledge base.
4. Return grounded answers WITH citations.
5. Test questions the knowledge base can and cannot answer (safe fallback).

Milestone: the app answers healthcare/appointment-policy questions from Foundry IQ
and shows where the information came from.
