# Frontend

Vite + React + TypeScript. Minimal on purpose - the learning focus is agents, not UI.

```bash
npm install
npm run dev     # http://localhost:3000 (proxies /api to the backend on :8000)
```

- `src/api.ts` backend calls
- `src/components/Chat.tsx` the chat UI
- `src/App.tsx` layout + disclaimer

Add the admin portal and appointment views here as you progress.
